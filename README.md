# LinkedIn営業管理

海外企業へのLinkedIn営業(コネクト申請 → DM → フォロー)を個人で管理するためのツールです。
LinkedIn APIとの自動連携は行わず、送信は手動、管理・下書き・進捗トラッキングを効率化することが目的です。

## 機能

- **連絡先管理** — 会社名・担当者名・役職・Tier(1〜3)・ステータスの管理、検索・フィルター、メモ
- **メッセージテンプレート管理** — カテゴリ別のテンプレートCRUD、プレースホルダー(`[Name]` `[Company]` `[Title]`)の自動置換とコピー用テキスト生成
- **フォローアップ管理** — 連絡先ごとのフォロー予定日、今日・今週の対応リストをダッシュボードに表示
- **KPIダッシュボード** — 週次/月次の送信数、返信率、ステータス別人数

## 開発

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) を開いてください。

## データ保存について

現在はブラウザのIndexedDBにデータを保存しています(`app/lib/db.ts`)。
`app/lib/repository.ts` の `Repository<T>` インターフェースに沿って実装されているため、
将来サーバーAPIやFirestoreなどに保存先を切り替える場合も、この interface を満たす新しいクラスを
1つ実装するだけで済み、hooksやコンポーネント側の変更は不要です。
